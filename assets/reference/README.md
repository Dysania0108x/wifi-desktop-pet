# Reference assets

Place original user-provided WiFi photographs and generated concept references here.

The current generated character-sheet reference is intended for visual direction only. It contains multiple poses and animation ideas on one sheet; it is not yet a clean sprite sheet suitable for runtime animation. Production assets should be recreated as individual transparent frames and checked against the real-photo references.

Keep personal reference photographs private and do not publish them in this public repository without an explicit decision. The generated concept reference may also be kept locally until its distribution/licensing status is reviewed.
